# 🐍💧🔫 Snake Water Gun Game

A simple **Snake-Water-Gun Game** developed using Python. This beginner-friendly mini project was created to practice Python programming concepts such as `if-else` statements, conditional logic, variables, user input, and random choices.

## 🎮 How the Game Works

The player chooses one option:

- 🐍 Snake
- 💧 Water
- 🔫 Gun

The computer randomly chooses one of the three options.

## 🏆 Game Rules

| Player Choice | Computer Choice | Result |
|---|---|---|
| 🐍 Snake | 💧 Water | 🎉 Player Wins |
| 💧 Water | 🐍 Snake | 💻 Computer Wins |
| 🔫 Gun | 🐍 Snake | 🎉 Player Wins |
| 🐍 Snake | 🔫 Gun | 💻 Computer Wins |
| 💧 Water | 🔫 Gun | 🎉 Player Wins |
| 🔫 Gun | 💧 Water | 💻 Computer Wins |
| Same Choice | Same Choice | 🤝 Draw |

## 💡 Example

If the player chooses **Snake 🐍** and the computer chooses **Water 💧**:

```text
Player: Snake 🐍
Computer: Water 💧

🎉 You Win!
```
##  If both the player and computer choose the same option:

Player: Gun 🔫
Computer: Gun 🔫

🤝 It's a Draw!
