# python-snake-game

A simple Snake Game mini project developed using Python. This project was created as part of my Python learning journey and demonstrates the use of basic programming concepts such as `if-else` statements, loops, variables, and user input.

## 🚀 Features

* Simple Snake Game
* Keyboard-based controls
* Score tracking
* Collision detection
* Uses basic Python programming concepts

## 🛠️ Technologies Used

* Python
* VS Code

## 📚 Concepts Practiced

* `if-else` statements
* Variables
* Loops
* Conditional logic
* User input
* Basic game logic

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Make sure Python is installed.
4. Run:

```bash
python snake_game.py
```

## 🎯 Purpose

This project was created to practice Python programming fundamentals by building a simple game.
